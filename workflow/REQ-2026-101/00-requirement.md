# REQ-2026-101 요구사항

## 배경 — 실측이 지목한 유일한 지렛대

사용자 문제: "적용한 프로젝트에서 변경 하나마다 수십분~1시간."

소비자 2곳(`44_yammy_sales`·`45_MBTI_kiosk`)의 `review-ledger.jsonl` **109개 티켓**을 분석했다.

| | yammy_sales | MBTI_kiosk |
|---|---|---|
| 분석 티켓 | 100 / 127 | 9 / 9 |
| 리뷰 호출 | 737 | 181 |
| **티켓 소요 중앙값** | **36.7분** | **103.6분** |
| Codex 리뷰 왕복 | 9% (중앙 51초) | 14% (중앙 71초) |
| **리뷰 라운드 사이(수정+테스트)** | **91%** (중앙 218초) | **86%** (중앙 207초) |

**티켓 시간의 86~91%가 "라운드 사이"**이고 그 안에 테스트 실행이 있다(소비자 테스트 파일:
yammy **278**개, MBTI **125**개). REQ-2026-100이 그 축을 겨눈 계층 규칙을 만들었다.

⚠️ 같은 조사에서 **tsx 기동 제거 가설은 반증됐다** — 기동 비용은 실재하나(482→73ms) 곱해질 자리가
없다(CLI 스폰 파일이 50개 중 4개 = 스위트의 2.2%). 소비자 명령에서도 tsx는 11%이고 npx 오버헤드가
37%로 더 크며, 티켓 시간 기준으로는 0.2% 미만이다. 그래서 이 REQ는 tsx가 아니라 **전달**을 다룬다.

## 현재 전달 상태 — 격차는 좁다 (실측)

REQ-2026-100의 규칙이 기존 소비자에게 닿는 경로를 확인했다.

| 표면 | 기존 설치본에 닿는가 | 근거 |
|---|---|---|
| `02-plan.md` 스캐폴드(계층 전문) | ✅ **닿는다** — 업그레이드하면 새 티켓부터 자동 | 스캐폴드는 설치된 패키지에서 생성된다(이 REQ의 `02-plan.md`로 확인) |
| `AGENTS.md` §1-1 | ❌ 안 닿는다 | `init`이 한 번 심은 뒤 소비자 소유·`sync` 대상 아님 |
| Quick Start 블록 | ⚠️ **기계는 있는데 신호가 없다** | 아래 |

즉 격차는 "규칙이 전혀 안 간다"가 아니라 **"항상 로드되는 계약에는 안 간다"**이다.

## 핵심 발견 — 갱신 기계는 이미 있고 탐지만 없다

- [bin/quickstart.ts:109-111](../../bin/quickstart.ts) — 블록이 이미 있어도 **내용이 다르면 교체**한다
  (`action: 'updated'`). 즉 **갱신 능력은 이미 있다.**
- [bin/quickstart.ts:177-186](../../bin/quickstart.ts) `missingQuickstartFiles` — **마커 부재만** 본다.
  내용이 낡았는지는 보지 않는다. 이 함수가 doctor **D21**의 유일한 입력이다
  ([req-doctor.ts:1114](../../scripts/req/req-doctor.ts)).

→ **블록 내용을 바꿔도 이미 설치된 소비자는 아무 신호를 받지 못하고, 따라서 아무도 `quickstart`를
실행하지 않는다.** 지금까지 Quick Start 블록을 한 번도 개정하지 않아 드러나지 않았던 구멍이다.

두 소비자 실측: 둘 다 `commitgate:quickstart` 마커를 갖고 있고(백필 이력 있음) 둘 다 `0.17.0`이다.
즉 **탐지만 생기면 즉시 수혜 대상**이다.

## 요구사항

- **R1** — Quick Start 블록이 **shipped와 다르면** 알린다(현재는 부재만 알림). 기존 소비자가
  `commitgate quickstart --apply`로 갱신할 수 있게 한다.
- **R2** — 판정은 **주입기가 쓰는 그 비교**를 재사용한다. 새 술어를 만들지 않는다
  (REQ-2026-099 교훈: 관찰이 갈라지면 한쪽만 참이 된다).
- **R3** — **WARN 상한**이다. 절대 FAIL이 아니다. 블록 내용은 소비자를 차단할 근거가 아니다
  (D20 자산 skew 선례와 동형).
- **R4** — 테스트 계층 규칙이 Quick Start 블록을 타고 흐르도록 **한 줄**을 넣는다. 전문은
  `AGENTS.md` §1-1과 `02-plan.md`에 있으므로 여기서는 짧게 — Quick Start는 "빠른 시작"이다.
- **R5** — 마커 **안쪽을 사람이 편집했을 수 있다**. 갱신이 그것을 덮어쓴다는 사실을 안내에 명시한다.

## 범위 밖

- **tsx 기동 제거** — 위 실측으로 반증됨(별도 REQ도 열지 않는다).
- **npx 오버헤드(950ms)** — tsx보다 크지만 여전히 티켓 시간의 1% 미만.
- `AGENTS.md` 본문(§1-1)을 자동 갱신하는 것 — 마커 밖 영역이라 소비자 소유다. 건드리지 않는다.

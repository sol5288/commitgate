# REQ-2026-074 설계 — 랜딩을 "훑어서 이해되는" 구조로

> 정본 결정은 SSOT(해당 DEC). 본 문서는 그 결정을 README에 어떻게 반영할지 기록.

## 현재 상태(변경 대상)

`README.md` / `README.en.md` 각 137행. 절 11개인데 **앞 4개 절이 전부 "이 도구가 뭔지"**를 설명한다:

```
15  ## 코드는 한 AI가 만들고, 다른 AI가 다시 봅니다   ← 왜 필요한가 (산문 3문단)
23  ## 사람은 결정에만 참여합니다                     ← 같은 얘기 (표)
32  ## 이렇게 흘러갑니다                              ← 같은 얘기 (번호 4단계)
39  ## 무엇을 보장하나요                              ← 계약
47  ## ⚠️ 시작 전에 알아 둘 것                         ← 비계약(경고 2건)
```

같은 것을 세 번 말하면 읽는 사람은 **세 번째까지 읽어야** 그림이 잡힌다.
그리고 그림 자체가 없다 — 누가 누구를 호출하는지는 98행의 텍스트 한 줄이 전부다.

## 핵심 설계 결정

### DEC-1 — 🔴 "무엇을 하는 도구인가"는 **한 절 + 그림**이다

`## CommitGate란?` 하나로 합치고 **ASCII 흐름도**를 그 안에 넣는다.
산문 세 절 → 한 문단 + 그림 + 기존 대비표.

왜: bluekiwi에서 실제로 효과가 있는 부분이 그것이다 — 다이어그램이 문장보다 먼저 온다.
🔴 다만 **그림이 문장을 대체하지는 않는다.** CommitGate의 핵심은 "누가 호출하는가"가 아니라
**"승인된 그 tree만 커밋된다"**는 계약이라, 그림 아래 한 문단이 반드시 남는다.

### DEC-2 — 🔴 보장과 비보장을 **붙여 놓는다**

지금은 39행(보장 3건)과 47행(경고 2건)이 떨어져 있어, 보장만 읽고 내려가면
"외부로 diff 전문이 나간다"·"git hook이 없어 우회된다"를 **못 보고 지나칠 수 있다**.

한 절 안에 **보장 / 보장하지 않는 것**을 나란히 둔다.
🔴 **경고를 표 칸에 욱여넣어 작게 만들지 않는다** — 두 항목은 표 아래 별도 강조 블록으로 남긴다.
표는 훑기 위한 것이고, 이 둘은 **읽어야 하는** 것이다.

### DEC-3 — 준비물을 설치 **앞**에 둔다

`docs/quick-start.md`에만 있던 준비물 표(Git · Node 18.17+ · 패키지 매니저 · Codex CLI)를
README 설치 절 앞에 **복제**한다.

🔴 복제를 감수하는 이유: Codex CLI가 없으면 설치는 성공하고 **리뷰 단계에서 실패**한다.
설치를 시작하기 전에 알아야 하는 정보를 다른 문서로 보내면, 알아야 할 사람이 못 본다.
🔴 대신 표는 "확인 명령"까지만 담고 **설치 방법은 quick-start로 보낸다** — 복제 면적을 줄인다.

### DEC-4 — `stopGate`는 **표 하나**로 올린다

setup의 세 질문 중 하나이고 워크플로 전체를 좌우하는데 지금은 한 문장이다.
세 값 × (언제 멈추나 / 누구에게 맞나) 표를 랜딩에 둔다.

🔴 확인 `scope` 대응·HIGH 취급 같은 상세는 **정본**(`docs/workflow.md`)에 남긴다 —
REQ-2026-073에서 정본을 한 곳으로 모은 결정을 되돌리지 않는다.

### DEC-5 — 🔴 **정보를 지우지 않는다**

재배치·압축이지 삭제가 아니다. companion skills 소개 · `/req` 사용 예시 ·
첫 응답 예시 · 명령표 · 문서 표 · 라이선스는 전부 남는다.

검증: phase 리뷰가 staged diff에서 **삭제된 사실**을 확인한다.
줄어드는 것은 **같은 말의 반복**이어야 한다.

### DEC-6 — 한국어를 먼저 확정하고 영어가 따라간다

phase를 나눈다(ko → en). 구조가 리뷰에서 흔들리면 영문을 두 번 쓰게 된다.
🔴 바이트 동일이 아니라 **같은 절 구성**이다(REQ-2026-073 DEC-5와 같은 이유 — 번역문을
한국어 문장 구조에 가두지 않는다). ASCII 흐름도는 라벨만 번역하고 **모양은 같게** 둔다.

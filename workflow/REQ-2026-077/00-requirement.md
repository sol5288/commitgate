# REQ-2026-077 요구사항 — macos node 18 스위트 교착의 근원 원인

## 왜 지금인가

`macos-latest · node 18`의 `npm test`가 2026-07-27 하루에 **두 번** 교착했다. 재실행하면 통과하므로
지금은 **플래키**로 취급되고 있는데, 그 대가가 이미 두 번 나왔다:

- 릴리스 CI를 통째로 막아 사람이 손으로 run을 중지해야 했다(REQ-2026-075의 `concurrency`가
  `main` 실행을 직렬화하므로 교착 하나가 다음 커밋의 검증을 세운다).
- 진행 중인 잡은 로그를 주지 않아, **원인을 보려면 잡을 죽여야 했다**.

🔴 그리고 **REQ-2026-044의 진단이 불완전하다는 증거**다. 044는 "파일 병렬이 스폰을 겹치게 해 hang한다"고
보고 전면 직렬로 갔는데, 교착 ①은 **그 전면 직렬 상태에서 났다.**

## 확보된 증거 (2026-07-27)

### 관측 2건

| 커밋 | 스위트 설정 | 경과 | 처리 |
|---|---|---|---|
| `86548e2` | `fileParallelism: false`(전면 직렬) | **35분+** | 사람이 run 취소 |
| `a368a77` | `maxWorkers: 2` | **13.6분+** | 사람이 run 취소 |

→ 🔴 **병렬 설정과 무관하다.** 직렬에서도 병렬에서도 난다.

### 로그 (`a368a77` 취소 후 확보)

```
14:08:19.94  ✓ tests/unit/docs-stale-claims.test.ts (10 tests) 20ms
             ← 12분간 출력 없음
14:20:16.60  ##[error]The operation was canceled.
14:20:19.49  Terminate orphan process: pid (2040) (esbuild)
```

- 테스트가 진행하다 **출력이 끊긴다** — 느려지는 것이 아니라 멈춘다.
- 정리 단계가 **고아 `esbuild` 프로세스**를 종료한다(tsx가 esbuild를 쓴다).

### 파일 단위 분석 — 용의자 1개

교착한 잡의 로그에 **끝내 등장하지 않은** 테스트 파일:

| 파일 | 판정 |
|---|---|
| `tests/unit/req-adapters-cmd.test.ts` | **정상** — `process.platform === 'win32'`가 아니면 skip |
| **`tests/unit/init.test.ts`** | 🔴 **용의자** |

`init.test.ts`는 **3318줄 · 201 tests**로 스위트 최대이고, 로컬 단독 실행에 **2분 36초**가 걸린다.
임시 저장소에 `commitgate init`을 반복 스폰하므로 고아 `esbuild`와 정합한다.

### 환경

- macOS 러너는 **arm64**(`/opt/homebrew/bin/git`).
- **Node 18은 EOL**(2025-04). 매트릭스에 남아 있는 최하 버전이다.
- 같은 커밋의 macos node 20·22는 매번 정상 통과했다 → **node 18에 한정**된 현상으로 보인다.

## 수용 기준

1. **재현 절차가 있다** — 사람이 따라 하면 교착을 만들 수 있는 절차. 🔴 이것이 이 REQ의 1차 산출물이다.
   재현 없이 원인을 주장하지 않는다.
2. 재현되면 **원인을 특정**한다(어느 스폰이 왜 반환되지 않는지).
3. 원인에 맞는 **조치**를 제안한다. 조치가 매트릭스 축소(node 18 제외)라면 **지원 범위 변경**이므로
   사용자 결정 사항으로 올린다 — 임의로 줄이지 않는다.
4. 🔴 **재현하지 못하면 거기서 멈추고 그 사실을 보고한다.** 못 찾은 것을 찾은 척하지 않는다 —
   이 종류 작업의 가장 큰 실패 모드다. 그때 산출물은 **관측 기록과 다음 조사 지점**이다.

## 범위 밖

- CI 타임아웃(REQ-2026-076에서 완료).
- 스위트 성능 개선(REQ-2026-075에서 완료).
- 스폰을 `main()` 직접 호출로 바꾸는 리팩터링 — 별개의 큰 작업이며, 이 교착의 **회피책**일 수는 있어도
  근원 원인 규명은 아니다.

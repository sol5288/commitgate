# REQ-2026-065 요구사항

리뷰 호출 auth preflight (bypass 없음)

## 배경

`commitgate setup`(REQ-2026-060)이 **setup 시점**에 codex 로그인을 확정하고,
`commitgate check`(REQ-2026-061)가 **요청 시점**에 진단할 수 있게 했다.
그러나 **리뷰 호출 경로 자체에는 여전히 확인이 없다.**

미로그인 상태로 `req:review-codex --run`을 돌리면:
1. 원장에 `attempt-opened`가 기록되고 **커밋된다**(durable 티켓).
2. 예산이 차감된다.
3. codex가 exit≠0으로 죽고 `ReviewCallError('dispatched')`로 분류되어 **차감이 유지된다**.
4. 사용자는 `codex 종료 코드 1`이라는 불투명한 메시지를 본다.

즉 **로그인만 안 됐을 뿐인데 예산을 잃고 원장에 고아 attempt가 남는다.**
setup 마커는 **팀 공유 설정 완료 사실**이지 개발자별 로그인을 보증하지 않으므로(REQ-2026-062 DEC-2),
이 축은 setup 게이트가 덮지 못한다.

## 요구사항

| # | 내용 |
|---|---|
| **R1** | 리뷰 호출 **직전**에 리뷰어 CLI 설치·로그인을 확인한다 |
| **R2** | 확인 실패는 **예산을 차감하지 않고** 고아 attempt도 남기지 않는다 |
| **R3** | 실패 메시지는 무엇을 해야 하는지 알려 준다 |

## 🔴 제약

### C1. probe는 원장 `attempt-opened` **이전**에 실행한다
원장은 호출 **전에** attempt를 기록하고 durable 티켓에서는 **커밋까지 한다**.
그 뒤에 probe하면 **고아 attempt가 남고 예산이 이미 소모된다** — 이 REQ가 막으려는 바로 그 상태다.

### C2. bypass 플래그를 만들지 않는다
`--skip-auth-probe` 류는 에이전트가 접근 가능한 fail-closed 우회다.
진단 실패를 일시적으로 숨길 뿐이고, 그러면 첫 리뷰가 다시 불투명하게 실패한다.

### C3. 🔴 `unknown`은 차단하지 않는다
auth probe는 **승인 무결성 게이트가 아니라 진단**이다. 로그인 부재는 *미리뷰 커밋*을 만들 수 없고
*실패한 리뷰*를 만들 뿐이다. 오탐 비용이 극단적으로 비대칭이다:

| 오탐 | 결과 |
|---|---|
| **false allow**(실제 미로그인인데 통과) | 호출이 codex에서 실패 = **오늘의 상태 그대로**. 예산 1회 차감 |
| **false block**(실제 로그인인데 `unknown`으로 차단) | codex가 `login status` 출력 문자열을 바꾸면 **전체 소비자의 모든 리뷰가 동시에 벽돌** |

→ `logged-out`(확정 신호)만 차단하고 `unknown`은 **WARN 후 진행**한다.
그리고 R1은 setup 시점의 확정 검증(REQ-2026-060)이 이미 1차로 충족한다 — 이건 2차 방어선이다.

## 🔴 비목표

| 비목표 | 이유 |
|---|---|
| **provider 추상화** | probe는 이미 `createReviewerProbes`로 추상화돼 있다. 이 REQ는 **연결**만 한다 |
| **`--dry-run` 경로 차단** | 실호출이 없으면 로그인도 필요 없다. `--run`일 때만 확인한다 |
| **로그인 실행** | 대화형이 필요하므로 `setup`의 소관이다. 여기서는 **안내만** 한다 |

## 수용 기준

1. 미로그인(`logged-out`)에서 `req:review-codex --run`이 **원장 기록 전에** 멈춘다.
2. 그 실패 후 원장에 attempt 행이 **없고** 예산이 차감되지 않는다.
3. `unknown`은 **차단하지 않고** 경고만 남긴 뒤 진행한다.
4. codex 미설치도 같은 지점에서 막힌다(설치가 먼저 확인된다).
5. bypass 플래그가 **존재하지 않는다**.
6. `--dry-run`(비실행) 경로는 영향받지 않는다.
7. `npm test` green · `tsc --noEmit` 0.
